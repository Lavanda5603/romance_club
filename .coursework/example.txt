P58: 1.1 АНАЛИЗ ЗВУКОВ СЕРДЦА И ИХ ЗНАЧЕНИЙ ДЛЯ ОБНАРУЖЕНИЯ ВОЗМОЖНЫХ ПАТОЛОГИЙ
P59: Звуки сердца, записанные при помощи специального оборудования, являются ценным источником информации о состоянии сердечно сосудистой системы. Само понятие фонокардиограмма (Далее ФКГ) – это метод, который позволяет регистрировать и визуализировать звуковые сигналы, производимые сердцем во время его работы. Данные сигналы возникают в результате механических примеров, в них входят сокращения миокарда, движения клапанов и кровотока. Анализ записей звуков работы сердца поможет выяснить патологии, такие как пороки клапанов, аритмии, сердечная недостаточность и другие нарушения.
P60: ФКГ представляет собой объективные данные в отличии от субъективной аускультации, зависящей от опыта врача. Записи ФКГ представляют собой временные ряды, которые в последствии можно анализировать с помощью нынешних технологий, включая методы обработки сигналов и машинное обучение. 
P61: Звуки сердца состоят из нескольких компонентов, которые связаны с фазами сердечного цикла – систолой и диастолой (сокращением желудочков и расслаблением желудочков соответственно). Основные элементы включают в себя:
P62: Первый сердечный тон (S1), который возникает в начале систолы, когда закрываются митральный и трикуспидальный клапаны. Тон S1 характеризуется низкой частотой и обычно звучит «луб». Он отражает начало выброса крови из желудочков в аорту и лёгочную артерию. Изменения в громкости или структуре S1 могут указать на какую-либо патологию;
P63: Второй сердечный тон (S2) возникает в начале диастолы, когда закрываются аортальный и лёгочный клапаны. Он звучит как «дуб» и имеет более высокую частоту, чем S1. Он может быть расщепленным из-за асинхронного закрытия клапанов, в некоторых случаях это норма, но иногда может указывать на патологию;
P64: Третий тон (S3) возникает в ранней диастоле из-за быстрого наполнения желудочков кровью. Он считается нормой для молодых людей и встречается чаще всего, в то время как у взрослых может указывать на сердечную недостаточность;
P65: Четвертый тон (S4) связан с сокращением предсердий и может быть один из признаков гипертрофии желудочков или снижения податливости сердечной мышцы; 
P66: Шумы сердца, которые возникают в результате турбулентного кровотока вызванного сужения клапанов, их недостаточностью или аномалиями. Шумы классифицируются по времени возникновения, интенсивности, частоте и локализации;
P67: Различные добавочные шумы, которые могут быть связаны с патологиями клапанов или движением структур сердца.
P68: Для анализа записи звуков сердца необходимо записать звуковые сигналы с высокой точностью. Полученные данные представляют собой временной ряд, который можно визуализировать в виде графика амплитуды звука во времени. Звуки сердца часто содержат посторонние шумы, для их устранения применяют цифровые фильтры, которые выделяют сигналы в диапазоне частот сердца, обычно это 20-500 Гц. Так же не мало важным является разделение записи на отдельные сердечные циклы, определяя границы S1 и S2. Это делается при помощи алгоритмов обнаружения пиков или синхронизации с ЭКГ. В рамках курсовой работы запись звуков сердца будет преобразовываться в мел-спектрограмму, которая будет представлять звук в частотно-временной области что удобно для анализа сложных сигналов.
P69: Таким образом, в данной курсовой работе будет представленная модель, которая будет определять по записям звуков сердца, есть ли патология в сердце или нет. Классифицировать патологии — это более сложная задача, требующая приличных затрат, включая финансовые и технологические. 
P70: 1.2 СПОСОБЫ ИЗВЛЕЧЕНИЯ ПРИЗНАКОВ ИЗ ЗВУКОВ СЕРДЦА С ИСПОЛЬЗОВАНИЕМ PYTHON 
P71: Python представляет множество библиотек, которые помогут при анализе звуков, в них входят SciPy и NumPy. Например, для фильтрации можно использовать функцию scipy.signal.butter для создания полосового фильтра, а для сегментации при помощи scipy.signal.find_peaks [19].
P72: Амплитуда тонов, интервалы между тонами, соотношение амплитуд, длительность шумов – это все временные признаки основанные на анализе амплитуды и длительности сигнала во времени. Для извлечения временных признаков в python используется библиотека Librosa которая предоставит функцию для анализа временных рядом, librosa.onset.onset_detect для обнаружения начала звуковых событий.

P74: Мел-спектрограммы – это одно из наиболее популярных временно-частотных представлений для анализа аудиоданных, включая ФКГ. Они представляют собой визуализацию спектра сигнала, где частоты преобразованы в мел-шкалу, которая соответствует восприятию звука человеческим ухом. Мел-спектрограммы крайне полезны для машинного обучения, так как они компактно представляют сложные аудиоданные в виде двумерного массива, пригодного для ввода в сверточные нейронный сети (CNN). Их можно получить с помощью функции librosa.feature.melspectrogram.

P173: 2.2 ТЕХНОЛОГИЯ ОБРАБОТКИ ЗВУКОВ СЕРДЦА
P174: Обработка звуков в данном проекте реализована с использованием языка python и библиотеки Librosa. Далее будет описана вся реализация обработки звуки.
P175: В предоставленном коде (см. Приложение Б), обработка звуков сердца начинается с загрузки аудиофайлов .wav, содержащих записи фонокардиограмм. Для это применяется функция librosa.load, которая читает аудиофайл и возвращает временной ряд звукового сигнала вместе с частотой дискретизации (sr). Частота дискретизации сохраняется в исходном коде без принудительного изменения, что позволяет учитывать естественные параметры записи, указанные в соответствующих  файлах .hea. Частота дискретизации может составлять 2000 Гц, как указано в метаданных, что достаточно для захвата звуков сердца в диапазоне 20-500 Гц. Данный подход обеспечивает сохранения всех релевантных компонентов сигнала. 
P176: Основным методом обработки аудиоданных является преобразование временного ряда в мел-спектрограмму, которая представляет собой двумерное временно-частотное представления сигнала, идеально подходящее для ввода в CNN. Для этого используется функция librosa.feature.melspectogram, которая принимает аудиосигналы и параметры на примере мел-фильтров n_mels-128. Выбор 128 мел-фильтров обеспечивает достаточную детализацию спектральных характеристик, включая низкочастотные тона и высокочастотные шумы, которые характерны для патологий.
P177: После получения мел-спектрограммы выполняется её преобразование в логарифмическую шкалу с помощью функции librosa.power_to_db. Это преобразование сжимает динамический диапазон амплитуд, делая спектрограмму более устойчивой к вариациям громкости записей и подчеркивая различия между нормальными и патологическими звуками. Логарифмическая мел-спектрограмма (далее МС) изменяется до фиксированного размера 128х128 пикселей с использованием функции resize из библиотеки skimage.transform. Данный шаг необходим для унификации входных данных, так как длительность записей может различаться, а CNN требует входные данные одинаковой формы. Сохранение качества спектральных паттернов при сглаживании артефактов при масштабировании реализуется при помощи параметра anti_aliasing=True в функции resize.

P185: 2.3 ОПРЕДЕЛЕНИЕ ЧАСТОТЫ СЕРДЕЧНЫХ СОКРАЩЕНИЙ НА ОСНОВЕ ЗВУКОВЫХ ДАННЫХ

ЧСС вычисляется с использованием аудиозаписей в формате .wav, входящих в набор данных, путем обнаружения пиков, соответствующих сердечным тонам S1 и S2 и анализа интервалов между ними. P189: Сигнал нормализируется делением на максимальное абсолютное значение амплитуды audio = audio / np.max(np.abs(audio)). Это приводит амплитуды к диапазону [-1;1], устраняя различия в громкости между записями и делая сигнал более устойчивым к вариациям оборудования или условиям записи. P199: 2.4 НАСТРОЙКА И ОБУЧЕНИЕ ИНТЕЛЛЕКТУАЛЬНОЙ МОДЕЛИ МАШИННОГО ОБУЧЕНИЯ
P200: Настройка и обучение интеллектуальной модели машинного обучения, является важным этапом в курсовой работе.
P201: В данном проекте используется свёрточная нейронная сеть (CNN), реализованная с помощью библиотеки TensorFlow, которая обрабатывает мел-спектрограммы аудиозаписей и метаданные пациентов. Настройка модели включает определение архитектуры, выбор гиперпараметров, компиляцию и подготовку данных, а обучение проводится с использование оптимизированного процесса, включающего разделение данных, пакетную обработку и раннюю остановку. Этот раздел описывает процесс настройки и обучения модели, с акцентом на архитектуру, параметры и стратегии оптимизации [11].
P202: Настройка модели начинается с подготовки входных данных, которые состоят из двух компонентов: мел-спектрограммы, метаданные. Мел-спектрограммы создаются с помощью библиотеки Librosa путём преобразования аудиофайлов в двумерное временно-частотное представление размеров 128х128 пикселей с 128 мел-фильтрами. Метаданные, включающие возраст и пол, извлекаются с помощью функции extract_metadata, которая парсит файлы .hea и возвращает числовые значения. Эти данные преобразуются в массивы NumPy; pcg_data с формой (N, 128, 128, 1) для мел-спектрограмм, meta_features с формой (N, 2) для метаданных и labels с формой (N) для бинарных меток.
P203: Данные организованы в объект tf.data.Dataset, который объединяет мел-спектрограммы  и метаданные в словарь с ключами pcg_input и meta_input. Датасет случайным образом перемешивается в словарь с ключами pcg_input и meta_input. Датасет случайным образом перемешивается с буфером 1024 и фиксированным зерном seed=42 для воспроизводимости, а затем разделяется на обучающую 80% и валидационную 20% выборки. Обучающая и валидационная выборки группируются в пакеты по 32 примера с использованием метода batch(32) и оптимизируются при помощи prefetch(tf.data.AUTOTUNE) для ускорения загрузки данных во время обучения. Такое разделение позволяет модели обучаться на большей части данных, сохраняя независимую валидационную выборку для оценки обобщающей способности. Данное разделение позволяет модели обучаться на большей части данных, сохраняя валидационную выбору для оценки обобщающей способности.
P204: Архитектура модели представляет собой комбинированную CNN с двумя входами. Входной слой мел-спектрограмм принимает данные формы (128, 128, 1) и последовательно обрабатывается тремя сверточными блоками.
P205: Первый блок включает в себя сверточный слой с 16 фильтрами 3х3, функцией активации ReLU и L2-регуляризацией с коэффициентом 0,01, за которым следует слой пулинга размеров 2х2.
P206: Второй и третий блоки аналогичны, но используют 32 и 64 фильтра соответственно, увеличивая глубину сети для извлечения более сложных признаков, после чего данные разворачиваются в вектор при помощи слоя Flatten.
P208: Рисунок  - Листинг кода с реализацией сверточных слоёв
P209: Входной слой для метаданных принимает данные формы и обрабатывается полносвязным слоем Dense с 16 нейронами и активацией ReLU. Выходы сверточной и полносвязной ветвей объединяются при помощи слоя Concatenate, формирую комбинированный вектор признаков. Этот вектор проходит через полносвязный слой с 128 нейронами и активацией ReLU, за которым следует слой выбросы Dropout с вероятностью 0,7 для предотвращения переобучения. Финальный слой Dense с одним нейроном и сигмоидной активацией выдаёт вероятность патологии.
P210: Модель компилируется с оптимизатором Adam, функцией потерь binary_crossentropy, подходящей для бинарной классификации, и метрикой accuracy для отслеживания производительности. Использование L2-регуляризации в сверточных сетях и высокого уровня выбросы (0.7) направлено на снижение переобучения, что особенно важно для медицинских данных, где вариативность может быть высокой. Архитектура модели выводится в консоль при помощи model.summary(),  предоставляя информация о количестве параметров и структуре слоев.
P211: Обучение модели проводится с использование метода model.fit, который выполняется на обучающем наборе (train_ds) в течении максимум 80 эпох. Валидационная выборка (val_ds) используется для мониторинга производительности после каждой эпохи. Для предотвращения переобучения и экономии времени применяется механизм ранней остановки, который отслеживает значение функции потерь на валидационной выборке. Если val_loss не улучшается в течении 5 эпох, обучение останавливается и веса модели восстанавливаются до лучших значений. Это обеспечивает выбор модели с оптимальной обобщающей способностью.
P212: После обучения модель сохраняется в файл heart_sound_cnn_model.keras для последующего использования.

Выбор мел-спектрограмм в качестве основного входа позволяет CNN улавливать спектральные и временные паттерны звуков сердца, такие как тоны S1, S2  и патологические шумы. Параметры, такие как размер пакета, количество эпох и ранняя остановка, оптимизированы для эффективного обучения на ограниченном наборе данных.
