# Мой дневник

В главном меню добавлена кнопка «Мой дневник». Записи сгруппированы по эпизодам и оформлены в бордовых цветах приложения. Игрок может только читать их.

Администратор открывает «разработчик» → эпизод → сцену → выбор и заполняет поле «Запись в “Мой дневник”». Затем сохраняет выбор, сцену и эпизод. Пустое поле отключает запись; максимум — 500 символов. Изменение текста сохраняет постоянную отметку записи. Удаление и повторное создание даёт новую отметку.

После выбора существующий игровой движок устанавливает отметку в прогрессе; запись появляется в дневнике после сохранения на сервере. Старые решения без отметок задним числом не добавляются. Просмотр дневника не начисляет баллы и не вызывает сохранение прогресса.

Текст берётся из актуальной истории: правка администратора меняет формулировку и у уже открытой записи. Это дневник текущей редакции истории, не неизменяемый архив прежних формулировок. Записи располагаются в порядке сцен и выборов эпизода.

Сброс эпизода очищает его отметки вместе с прогрессом. Дневник читает только собственное сохранение каждого эпизода, поэтому перенесённые флаги в более поздних эпизодах не возвращают старые записи. Полный сброс очищает дневник. Действующие ограничения размера прогресса распространяются и на отметки дневника.

Используется совместимый тип действия changeFlag с постоянным ключом diary_ и текстом в title. Новый Protobuf-контракт и миграция не требуются. Сохранение текстов ограничено существующими серверными правами администратора. После сохранения изменений истории нужно заново открыть игру, чтобы она загрузила обновлённый эпизод.

Для проверки: задать запись в редакторе, сохранить эпизод, выбрать этот ответ в игре, выйти с сохранением, открыть дневник. Затем перезапустить эпизод и убедиться, что запись исчезла. Проверка на реальном устройстве для этой доработки ещё не выполнена.
