# Запуск на телефоне и другом компьютере

Адрес сервера теперь меняется в приложении без пересборки: на экране входа нажми «Подключение к серверу». Если проверка сохранённой сессии не проходит, эта кнопка есть и на экране ошибки запуска. После смены адреса нужно войти заново: токен прежнего сервера очищается.

## Телефон по USB

1. На компьютере преподавателя должны работать SurrealDB с нужной базой, картинками и Rust-сервер проекта. Одного кабеля и APK недостаточно. Перенеси проект и данные заранее; секреты и резервные копии БД не публикуй в Git.
2. Запусти БД, затем `start-server.cmd`. Для USB сервер может оставаться на `127.0.0.1:50051`.
3. Включи на Android «Для разработчиков» → «Отладка по USB», подключи кабель с передачей данных и подтверди доверие компьютеру на телефоне.
4. На ПК должны быть Android SDK Platform Tools. Выполни `adb devices`: телефон должен иметь статус `device`, а не `unauthorized`.
5. Выполни `adb -d reverse tcp:50051 tcp:50051` или запусти `connect-phone.cmd`. При нескольких настоящих телефонах используй `adb -s СЕРИЙНЫЙ_НОМЕР reverse tcp:50051 tcp:50051`.
6. Установи новую сборку приложения с экраном подключения. В нём выбери «Телефон по USB»: адрес `127.0.0.1`, порт `50051`. Сохрани и войди в аккаунт этой БД.

Проброс нужно повторить после переподключения или перезапуска телефона. Чтобы удалить его, выполни `adb -d reverse --remove tcp:50051`. `10.0.2.2` предназначен для Android-эмулятора и не подходит настоящему телефону.

## Через общую Wi-Fi сеть

На экране подключения укажи локальный IPv4 компьютера, например `192.168.1.10`, без `http://` и без порта в поле адреса. Порт указывается отдельно. Перед запуском сервера в PowerShell задай `$env:GRPC_BIND = '0.0.0.0:50051'`. Разреши входящий TCP 50051 только для доверенной локальной сети. Порт SurrealDB телефону открывать не нужно. Учебный gRPC работает без TLS: не открывай его в интернет.

Адрес сохраняется после закрытия приложения. Исходный адрес можно также задать при сборке: `flutter build apk --release --dart-define=GRPC_HOST=127.0.0.1`. Сохранённая пользователем настройка имеет приоритет.
