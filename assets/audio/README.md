# Музыка и звук кнопок

Сохраняю общую фоновую музыку как `background_music.mp3`, а короткий звук кнопки как `button_click.mp3` в этой папке. Оба файла могут быть MP3.

Оба файла подключены через `AppAudio`. Общая музыка играет с повтором, а щелчок использует отдельный проигрыватель. Переход между экранами не создаёт музыку заново.

Ползунки сразу меняют громкость. Кнопка «сохранить» записывает значения, выход без сохранения возвращает прежнюю громкость. Ноль выключает соответствующий звук. При сворачивании ставлю звук на паузу, при возврате продолжаю музыку.

Щелчок вызываю из обработчика кнопки, поэтому он работает и при нажатии Enter. Отключённые кнопки и движение ползунков не щёлкают. Ошибка аудиофайла не отменяет действие кнопки.
